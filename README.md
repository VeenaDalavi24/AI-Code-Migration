# AI-Based Code Migration Web Application with Intelligent Verification

## Overview

This project aims to modernize legacy COBOL code by converting it into Python and verifying the converted program through automated validation and testing.

## Key Features

* COBOL code analysis
* AI-powered COBOL-to-Python conversion
* Python syntax and AST validation
* Automated test case generation
* Differential output verification
* AI-assisted error correction and re-testing
* Migration report generation

## Technology Stack

* Python
* Streamlit
* OpenAI API
* Python AST
* Automated testing tools

## Installation and Usage

1. Clone this repository.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Configure your API key securely using an environment variable.
4. Run the application using the appropriate Streamlit entry file, for example `streamlit run app.py`.
